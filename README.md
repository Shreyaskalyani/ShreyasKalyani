## About

I'm a cybersecurity professional specializing in web application security, penetration testing, and vulnerability research. My work spans the OWASP Top 10 (XSS, SQLi, SSRF, CSRF, CORS, IDOR), offensive security testing with tools like Burp Suite and Metasploit, and building automated tools to speed up vulnerability discovery.

I'm Certified Ethical Hacker (CEH) and a Certified Penetration Tester, and I stay sharp through bug bounty programs (HackerOne, Bugcrowd) and CTF platforms (TryHackMe, HackTheBox).

**Currently focused on:** building AI-assisted security tooling and expanding into red team operations.
